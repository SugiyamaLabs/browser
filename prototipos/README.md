# prototipos

Protótipos navegáveis em HTML, um arquivo por tela. Abrir direto no navegador; não é código do app.

| Arquivo | O que é |
|---|---|
| `janela.html` | a janela (#17): abas em cima ou na lateral, perfis, barra de endereço, aba dormindo, nova aba, sem rede, claro/escuro. As variáveis CSS do topo são o rascunho dos tokens (#16). |
